# Лендинг «Личная CRM»

Одна статичная страница: рассказывает о приложении и ведёт в него кнопкой «Открыть приложение» (`https://app.lichnaya-crm.ru`).

## Запуск на своём компьютере

```bash
pnpm install     # один раз: поставить зависимости
pnpm dev         # режим разработки: http://localhost:4321, правки видны сразу
pnpm build       # собрать готовый сайт в папку dist/
pnpm preview     # показать собранный сайт: http://localhost:4321
```

## Где что лежит

- `design/` — макет из Claude Design: `README.md` с токенами и описанием блоков, HTML-образцы мобильной и десктопной версии, исходный текст
- `src/data/landing.ts` — все тексты страницы, дословно из макета
- `src/config.ts` — адрес приложения для кнопок
- `src/styles/tokens.css` — цвета, шрифты, размеры текста и отступы
- `src/styles/global.css` — фактуры бумаги: линейка, клетка, поля, перфорация, рваные края
- `src/components/` — блоки страницы: первый экран, проблема, решение, выгоды, стикер
- `public/` — файлы как есть: зернистость бумаги и иконка вкладки

## Шрифты

Шрифты лежат внутри сайта (пакеты Fontsource), ничего не грузится с Google.
Alegreya и Caveat — вариативные версии: это те же файлы, что Google Fonts отдаёт макету, поэтому буквы совпадают с макетом до пикселя.
